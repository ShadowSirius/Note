# 〜ないまでも

## 規則與接續
- `動詞ない形 + までも`
- `名詞・な形容詞 + でないまでも`

## 用法說明
意為「雖不至於...，但至少...」，前項提出一個較高標準並否定達到該標準，後項則提出一個相對較低但仍應達成的標準，語感為退一步讓步求，常見於建議、要求的書面表達。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E"><ruby>毎日<rt>まいにち</rt></ruby>とは</span><span style="color:#3498DB"><ruby>言<rt>い</rt></ruby>わないまでも、</span><span style="color:#2ECC71"><ruby>週<rt>しゅう</rt></ruby>に<ruby>一度<rt>いちど</rt></ruby>は</span><span style="color:#3498DB"><ruby>連絡<rt>れんらく</rt></ruby>してほしい。</span>
  中文：雖不至於要求每，但希望至少一週聯絡一次。
- 日文：<span style="color:#FF477E"><ruby>完璧<rt>かんぺき</rt></ruby>とは</span><span style="color:#3498DB"><ruby>言<rt>い</rt></ruby>えないまでも、</span><span style="color:#2ECC71">かなりの</span><span style="color:#3498DB"><ruby>出来<rt>でき</rt></ruby>だ。</span>
  中文：雖不能說完美，但已經是相當不錯的成果了。
