# 〜のきわみ

## 規則與接續
- `名詞 + の極み`

## 用法說明
意為「...之極」，與 [[JP_N1_16_no_itari|〜の至り @related_to]] 意義相近，但「のきわみ」接續範圍較廣，可用於各種正負面情感或狀態的極致（贅沢の極み・疲労の極み・悲しみの極み等），書面誇張表現，常見於文學與評論。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71">この<ruby>料理<rt>りょうり</rt></ruby>は</span><span style="color:#3498DB"><ruby>贅沢<rt>ぜいたく</rt></ruby>の<ruby>極<rt>きわ</rt></ruby>みだ。</span>
  中文：這道料理奢華至極。
- 日文：<span style="color:#2ECC71"><ruby>連日<rt>れんじつ</rt></ruby>の<ruby>残業<rt>ざんぎょう</rt></ruby>で</span><span style="color:#3498DB"><ruby>疲労<rt>ひろう</rt></ruby>の<ruby>極<rt>きわ</rt></ruby>みに<ruby>達<rt>たっ</rt></ruby>している。</span>
  中文：連日加班已達疲勞的極限。
