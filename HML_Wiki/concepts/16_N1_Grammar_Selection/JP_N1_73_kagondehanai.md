# 〜と言っても過言ではない

## 規則與接續
- `普通形 + と言っても過言ではない`

## 用法說明
意為「說..也不為過」，表示雖然這樣的說聽起來有些誇張，但實際上是恰如其分、合理的評價，用於強烈肯定、稱讚某人事物，語感為「這麼說點也不誇張」，屬正式書面評論用語。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

  中文：說是天才也不為過。
- 日文：<span style="color:#2ECC71">この<ruby>発見<rt>はっけん</rt></ruby>は</span><span style="color:#3498DB"><ruby>歴史<rt>れきし</rt></ruby>を<ruby>変<rt>か</rt></ruby>えたと<ruby>言<rt>い</rt></ruby>っても<ruby>過言<rt>かごん</rt></ruby>ではない。</span>
  中文：說項發現改變了歷史也不為過。
