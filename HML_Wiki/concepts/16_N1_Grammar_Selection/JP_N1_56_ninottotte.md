# 〜に則って

## 規則與接續
- `名詞 + に則って`（のっとってのっとって多接「伝統・慣例・法律・規則・方針」等規範類名詞）
- 連體修飾時作「に則った」+ 名詞

## 用法說明
意為「遵循...規範、準則」，強調依照既定的規則、慣例、傳統、法律等權威性基準行事，比「〜に従って」更正式、更強調對規範本身的尊重與依循。與 [[JP_N1_55_nisokushite|〜に即して @related_to]] 對照：「に則って」接對象是規則／傳統等「規範」，「に即して」接對象是事實／現狀等「實情」。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E"><ruby>伝統<rt>でんとう</rt></ruby>に<ruby>則<rt>そく</rt></ruby>って、</span><span style="color:#3498DB"><ruby>式<rt>しき</rt></ruby>を<ruby>執り行<rt>とりおこな</rt></ruby>う。</span>
  中文：依循傳統舉行儀式。

  中文：依法處理。
