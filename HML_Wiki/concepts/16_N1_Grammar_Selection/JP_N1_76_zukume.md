# 〜ずくめ

## 規則與接續
- `名詞 + ずくめ`（多接「黒・いいこと・規則」等）

## 用法說明
意為「清一色都是...、淨是...」，表示從頭到尾、全部都是同一種事物或狀態，可用於正面（いいことずくめいいことずくめ淨是好事）或中性（黒ずくめずくめ一身黑）語境。與 [[JP_N1_75_mamire|〜まみれ @related_to]] 對照：「ずくめ」不限負面，強調「全部、一致」，「まみれ」則多用於負面、強調「沾附在表面」。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71"><ruby>今年<rt>ことし</rt></ruby>は</span><span style="color:#3498DB">いいことずくめの<ruby>一年<rt>いちねん</rt></ruby>だった。</span>
  中文：今年是滿是好事的一年。
- 日文：<span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#FF477E"><ruby>黒<rt>くろ</rt></ruby>ずくめの</span><span style="color:#3498DB"><ruby>服装<rt>ふくそう</rt></ruby>で<ruby>現<rt>あらわ</rt></ruby>れた。</span>
  中文：他穿著一身黑色的服裝出現了。
