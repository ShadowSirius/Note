# 〜の余り／〜あまり

## 規則與接續
- `名詞 + の余り`（書面語感較強）
- `動詞辭書形／い形容詞／な形容詞（な） + あまり（に）`（適用範圍較廣，接名詞亦可：`名詞の + あまり`）

## 用法說明
意為「過於...以致於...」，表示因情感或狀態過度而導致某種（多為異常、意外或負面的）結果。「の余り」較文語、偏書面，僅接名詞名詞「あまり」除接名詞外還可接動詞、形容詞，日常書面皆可用，適用範圍更廣、更為常見。兩者語意相通，可視為同一文法的書面／通用變體。

> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞
