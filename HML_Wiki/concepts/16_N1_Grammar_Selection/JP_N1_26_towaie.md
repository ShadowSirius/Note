# 〜とはいえ

## 規則與接續
- `名詞・普通形 + とはいえ`

## 用法說明
意為「雖說..但是...」，先承認前項事實，再提出與預期不完全一致的後項評價或轉折，語氣較 [[JP_N1_09_to_iedomo|〜と言えども @related_to]] 稍軟、使用範圍更廣，可用於日常書面（報告、隨筆），是N1讓步現中最常見、最實用的一項。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E"><ruby>春<rt>はる</rt></ruby>とはいえ、</span><span style="color:#2ECC71">まだ</span><span style="color:#3498DB"><ruby>朝晩<rt>あさばん</rt></ruby>は<ruby>寒<rt>さむ</rt></ruby>い。</span>
  中文：雖說是春天，但早晚是很冷。
- 日文：<span style="color:#FF477E"><ruby>子供<rt>こども</rt></ruby>とはいえ、</span><span style="color:#3498DB">もう15<ruby>歳<rt>とし</rt></ruby>だから<ruby>責任<rt>せきにん</rt></ruby>を<ruby>持<rt>も</rt></ruby>たせるべきだ。</span>
  中文：雖說小孩，但已經15歲，應該讓他負起責任。
