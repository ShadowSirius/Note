# 〜がゆえに

## 規則與接續
- `動詞・い形容詞普通形 + がゆえに`
- `名詞・な形容詞（である）+ がゆえに`

## 用法說明
文語書面因果表現，意為「正因為...、由於...」，用於客觀陳述前項是後項的原因，語氣比「〜から」「〜ので」更硬、更具論說判決書色彩。與 [[JP_N1_30_bakoso|〜ばこそ @related_to]] 同屬N1書面因果表現，但語感不同：「がゆえに」偏向客觀陳述因果關係，「ばこそ」則強調「正因為...才...」的主觀決定性理由。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E"><ruby>経験<rt>けいけん</rt></ruby>が<ruby>浅<rt>あさ</rt></ruby>いがゆえに、</span><span style="color:#3498DB"><ruby>失敗<rt>しっぱい</rt></ruby>を<ruby>繰り返<rt>くりかえ</rt></ruby>した。</span>
  中文：因為經驗尚淺，所以屢失敗。
- 日文：<span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#FF477E"><ruby>天才<rt>てんさい</rt></ruby>であるがゆえに、</span><span style="color:#3498DB"><ruby>孤独<rt>こどく</rt></ruby>を<ruby>感<rt>かん</rt></ruby>じることも<ruby>多<rt>おお</rt></ruby>い。</span>
  中文：正因為是天才，也常常感到孤獨。
