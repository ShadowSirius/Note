# 〜には当たらない

## 規則與接續
- `動詞辭書形／する動詞語幹 + には当たらない`

## 用法說明
意為「不至於、不值..」，表示某事的程度不到需要做出後項反應（驚訝、稱讚、責備等）的地步有「不必反應過度」的冷靜判斷語氣，常搭配「驚く・褒める・非難する」等動詞。與 [[JP_N1_70_mademonai|〜までもない @related_to]] 對照：「には当たらない」聚焦「反應程度不需要那麼強烈」，「までもない」聚焦「動作本身沒必要做」。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E">この<ruby>程度<rt>ていど</rt></ruby>のミスなら、</span><span style="color:#3498DB"><ruby>非難<rt>ひなん</rt></ruby>するには<ruby>当<rt>あ</rt></ruby>たらない。</span>
  中文：這種程度的失誤，不至於要責備。
- 日文：<span style="color:#2ECC71"><ruby>彼<rt>か</rt></ruby>の</span><span style="color:#FF477E"><ruby>成功<rt>せいこう</rt></ruby>は、</span><span style="color:#3498DB">それほど<ruby>驚<rt>おどろ</rt></ruby>くには<ruby>当<rt>あ</rt></ruby>たらない。</span>
  中文：他的成功，不值那麼驚訝。
