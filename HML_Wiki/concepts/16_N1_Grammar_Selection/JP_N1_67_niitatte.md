# 〜に至って

## 規則與接續
- `名詞 + に至って`
- `動詞辭書形 + に至って`（多接「ここ・この段階・この期に及んで」等表達事態發展階段的詞）

## 用法說明
意為「直到...才、到了...階段」，表示直到事態發展到某個（通常是極端、嚴重的）階段，才終於發生某種認知或行動，帶有「事已至此、為時已晚語感，常搭配「ようやく・初めて」。與 [[JP_N1_68_niitarumade|〜に至るまで @related_to]] 字形相近但意義不同：「に至って」表「到了某階段」，「に至るまで」表「範圍延伸到...」。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E"><ruby>事態<rt>じたい</rt></ruby>がここに<ruby>至<rt>いた</rt></ruby>って、</span><span style="color:#2ECC71">ようやく<ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#3498DB">ことの<ruby>重大<rt>じゅうだい</rt></ruby>さに<ruby>気<rt>き</rt></ruby>づいた。</span>
  中文：事態發展到這個地步他才終於察覺事態的嚴重性。
- 日文：<span style="color:#FF477E"><ruby>破産<rt>はさん</rt></ruby>に<ruby>至<rt>いた</rt></ruby>って、</span><span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#3498DB"><ruby>自分<rt>じぶん</rt></ruby>の<ruby>甘<rt>あま</rt></ruby>さを<ruby>悔<rt>く</rt></ruby>いた。</span>
  中文：直到破產他才後悔自己的天真。
