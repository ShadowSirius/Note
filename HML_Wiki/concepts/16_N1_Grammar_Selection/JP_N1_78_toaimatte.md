# 〜と相まって

## 規則與接續
- `名詞 + と相まって`（あいまってあいまって書面上亦作「〜と相俟って」，意義完全相同）

## 用法說明
意為「與...相輔相成、加乘作用下」，表示兩個或多個因素相互作用、彼此加乘，共同產種效果，語感中性偏正面，常見於分析報導、評論文章，強調多重因素的協同效應。「相俟って」為同義異形漢字表記，書面上兩者可互換。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E"><ruby>円安<rt>えんやす</rt></ruby>と<ruby>相<rt>そう</rt></ruby>まって、</span><span style="color:#3498DB"><ruby>輸出<rt>ゆしゅつ</rt></ruby>が<ruby>好調<rt>こうちょう</rt></ruby>だ。</span>
  中文：在日圓貶值加乘作用下，出口表現良好。
- 日文：<span style="color:#FF477E"><ruby>美<rt>うつく</rt></ruby>しい<ruby>景色<rt>けしき</rt></ruby>と<ruby>相<rt>そう</rt></ruby>まって、</span><span style="color:#2ECC71"><ruby>旅<rt>たび</rt></ruby>の<ruby>思い出<rt>おもいで</rt></ruby>は</span><span style="color:#3498DB">より<ruby>一層<rt>いっそう</rt></ruby><ruby>深<rt>ふか</rt></ruby>いものになった。</span>
  中文：與美麗的景色相輔相成，旅行的回憶變得更加深刻。
