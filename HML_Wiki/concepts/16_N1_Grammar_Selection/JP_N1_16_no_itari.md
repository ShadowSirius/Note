# 〜の至り

## 規則與接續
- `名詞 + の至り`（多接「光栄・感激・赤面・汗顔」等固定名詞）

## 用法說明
意為「真是...到了極點」，多用於致辭、獲獎感言等最高鄭重場合，表達說情感（多為榮幸、羞愧）達到極致，屬高度固定化的慣用搭配，接續名詞範圍狹窄（幾乎只用於「光栄の至り」「若気の至り」等），不可任意替換。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E">このような<ruby>賞<rt>しょう</rt></ruby>をいただき、</span><span style="color:#3498DB"><ruby>光栄<rt>こうえい</rt></ruby>の<ruby>至<rt>いた</rt></ruby>りです。</span>
  中文：能獲得如此獎項，實在是無上光榮。
- 日文：<span style="color:#FF477E">あの<ruby>頃<rt>ごろ</rt></ruby>の<ruby>行動<rt>こうどう</rt></ruby>は</span><span style="color:#3498DB"><ruby>若気<rt>わかげ</rt></ruby>の<ruby>至<rt>いた</rt></ruby>りだった。</span>
  中文：那時候的行為真是年少輕狂啊
