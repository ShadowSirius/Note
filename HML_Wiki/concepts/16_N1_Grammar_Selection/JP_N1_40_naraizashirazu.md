# 〜ならいざしらず

## 規則與接續
- `名詞・普通形 + ならいざしらず`

## 用法說明
意為「如果是...還說過去，但...」，先舉出一個能被接受或理解的極端／假設情況，再以強烈對比指出實際情況完全不同、更不可接受，語氣帶批判色彩，常見於指責、抱怨的書面表達。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E"><ruby>初心者<rt>しょしんしゃ</rt></ruby>ならいざしらず、</span><span style="color:#2ECC71">プロが</span><span style="color:#3498DB">こんなミスをするなんて<ruby>信<rt>しん</rt></ruby>じられない。</span>
  中文：如果是初學者還說過去，但職業選手犯這種錯真令人難以置信。
- 日文：<span style="color:#FF477E"><ruby>子供<rt>こども</rt></ruby>ならいざしらず、</span><span style="color:#2ECC71"><ruby>大人<rt>おとな</rt></ruby>が</span><span style="color:#3498DB">そんな<ruby>行動<rt>こうどう</rt></ruby>をするのは<ruby>恥<rt>は</rt></ruby>ずかしい。</span>
  中文：如果是小孩還說過去，但大人做出那種行為實在丟。
