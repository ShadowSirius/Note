# 〜ばこそ

## 規則與接續
- `動詞・形容詞假定形（ば） + こそ`
- `名詞・な形容詞 + であれば + こそ`

## 用法說明
意為「正因為...才...」，強調前項是後項成立的唯一、決定性理由，語氣比「〜から」更強烈、更具說，句尾常搭配「〜のだ」加強論斷語氣，屬N1書面因果表現的核心項目之一。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E"><ruby>愛<rt>いと</rt></ruby>していればこそ、</span><span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#3498DB"><ruby>厳<rt>いかめ</rt></ruby>しく<ruby>叱<rt>しか</rt></ruby>ったのだ。</span>
  中文：正因為愛他，他才嚴厲訓斥了。
- 日文：<span style="color:#FF477E"><ruby>信頼<rt>しんらい</rt></ruby>していればこそ、</span><span style="color:#2ECC71"><ruby>私<rt>わたし</rt></ruby>は</span><span style="color:#3498DB">この<ruby>仕事<rt>しごと</rt></ruby>を<ruby>任<rt>まか</rt></ruby>せたのだ。</span>
  中文：正因為信任，我才把這份工作交給他。
