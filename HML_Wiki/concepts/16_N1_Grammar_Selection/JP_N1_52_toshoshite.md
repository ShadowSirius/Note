# 〜と称して

## 規則與接續
- `名詞・動詞辭書形 + と称して`

## 用法說明
意為「號稱、以...名義」，用於指出某人以某種名目或藉口行事，但暗示該名目可能與實際行為不符，帶有懷疑、揭的批判語氣，常見於報導詐騙、藉口行為的新聞文脈。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

  中文：他號稱是投資顧問，騙取了高齡者的金錢。
- 日文：<span style="color:#FF477E"><ruby>視察<rt>しさつ</rt></ruby>と<ruby>称<rt>しょう</rt></ruby>して、</span><span style="color:#2ECC71"><ruby>職員<rt>しょくいん</rt></ruby>たちは</span><span style="color:#3498DB"><ruby>海外旅行<rt>かいがいりょこう</rt></ruby>を<ruby>楽<rt>たの</rt></ruby>しんでいた。</span>
  中文：以視察為名，職員們其實在享受海外旅行。
