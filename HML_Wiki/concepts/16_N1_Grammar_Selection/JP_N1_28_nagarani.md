# 〜ながらに（して）

## 規則與接續
- `動詞ます形・名詞 + ながらに（して）`（多接「生まれ・涙・昔」等固定名詞／連用形）

## 用法說明
意為「保持...狀態、依然...」，表示在維持某狀態或姿勢不變的情況下進行後項動作，是「〜ながら」的文語強化版，接續對象較固定（生まれながらにながらに天生、涙ながらにながらに含淚地、昔ながらのながらの一如往昔的），書面色彩濃厚。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71"><ruby>彼女<rt>かのじょ</rt></ruby>は</span><span style="color:#FF477E"><ruby>生<rt>う</rt></ruby>まれながらにして</span><span style="color:#3498DB"><ruby>才能<rt>さいのう</rt></ruby>に<ruby>恵<rt>めぐ</rt></ruby>まれていた。</span>
  中文：她生就富有才能。
- 日文：<span style="color:#2ECC71"><ruby>被害者<rt>ひがいしゃ</rt></ruby>は</span><span style="color:#FF477E"><ruby>涙<rt>なみだ</rt></ruby>ながらに</span><span style="color:#3498DB"><ruby>当時<rt>とうじ</rt></ruby>の<ruby>状況<rt>じょうきょう</rt></ruby>を<ruby>語<rt>かた</rt></ruby>った。</span>
  中文：受害者含淚訴說當時的狀。
