# 〜にとどまらず

## 規則與接續
- `名詞・動詞辭書形 + にとどまらず`

## 用法說明
意為「不僅限於...」，用於指出某影響、範圍超越了原先較小的界線，擴及更廣的層面，書面評論語氣，常見於論述影響力擴大的文脈（例：問題は国内にとどまらず、世界へと広がった）。與 [[JP_N1_36_nikagittakotodewanai|〜に限ったことではない @related_to]] 意義相近，但「にとどまらず」更強調範圍的擴張延伸，語氣更正式。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E">その<ruby>影響<rt>えいきょう</rt></ruby>は</span><span style="color:#2ECC71"><ruby>国内<rt>こくない</rt></ruby>に</span><span style="color:#3498DB">とどまらず、<ruby>世界<rt>せかい</rt></ruby>へと<ruby>広<rt>ひろ</rt></ruby>がった。</span>
  中文：那個影響不僅限於國內還擴及到了全世界。
- 日文：<span style="color:#FF477E"><ruby>彼<rt>か</rt></ruby>の<ruby>活躍<rt>かつやく</rt></ruby>は</span><span style="color:#2ECC71">スポーツ<ruby>界<rt>かい</rt></ruby>に</span><span style="color:#3498DB">とどまらず、<ruby>幅広<rt>はばひろ</rt></ruby>い<ruby>分野<rt>ぶんや</rt></ruby>に<ruby>及<rt>およ</rt></ruby>ぶ。</span>
  中文：他的活躍不僅限於運動界，還涉廣泛的領域。
