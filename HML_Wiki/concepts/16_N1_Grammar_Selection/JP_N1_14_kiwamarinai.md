# 〜極まりない

## 規則與接續
- `な形容詞語幹 + 極まりない`
- `形容詞・な形容詞語幹 + の + 極まりない`（較少見）

## 用法說明
表示「極其...、...到極點」，用於強調某種負面或強烈的評價性感受達到極限，語感比「とても」更誇張、更書面化，常接續於帶批判色彩的な形容詞（失礼・危険・不愉快等）。與 [[JP_N1_15_kiwamaru|〜極まる @related_to]] 意義相同，「極まりない」字面為「沒有極限、無止境」，以單一否定「ない」表達「已達極限」的強調語意（並非雙重否定），為固定慣用表現，不可拆解分析。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

  中文：他的態度極其失禮。
- 日文：<span style="color:#FF477E">そんな<ruby>運転<rt>うんてん</rt></ruby>は</span><span style="color:#3498DB"><ruby>危険<rt>きけん</rt></ruby><ruby>極<rt>きわ</rt></ruby>まりない。</span>
  中文：那樣的開車方式危險至極。
