# 〜あっての

## 規則與接續
- `名詞A + あっての + 名詞B`

## 用法說明
意為「有了...才有...的存在前提」，表示名詞B的存在或成立完全依賴於名詞A，若無A則B不可能存在，語感強調根本、不可或缺的因果依存關係，常見於格言式表達（例：「お客様あっての商売」顧客才是生意的根本）。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71"><ruby>命<rt>いのち</rt></ruby>あっての</span><span style="color:#3498DB"><ruby>物種<rt>ものだね</rt></ruby>だ。</span>
  中文：有命才有一切（留得青山在，不怕沒柴燒）。
- 日文：<span style="color:#2ECC71">お<ruby>客様<rt>きゃくさま</rt></ruby>あっての</span><span style="color:#3498DB"><ruby>商売<rt>しょうばい</rt></ruby>だから、</span><span style="color:#FF477E"><ruby>接客<rt>せっきゃく</rt></ruby>を<ruby>大切<rt>たいせつ</rt></ruby>にする。</span>
  中文：因為有顧客才有生意，所以重視待客之道。
