# 〜つ〜つ

## 規則與接續
- `動詞ます形 + つ + 動詞ます形（多為對照動詞） + つ`（固定成對，如「行きつ戻りつ」「持ちつ持たれつ」）

## 用法說明
意為「一邊...一邊...」，用於描述兩個相對或交替的動作反覆發生，屬高度固定化的四字慣用格式，現代日語僅存少數幾個固定搭配（行きつ戻りつ・持ちつ持たれつ・抜きつ抜かれつ），不可自由造句，文學、敘事語感濃厚。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#3498DB"><ruby>部屋<rt>へや</rt></ruby>の<ruby>中<rt>なか</rt></ruby>を<ruby>行<rt>い</rt></ruby>きつ<ruby>戻<rt>もど</rt></ruby>りつしていた。</span>
  中文：他在房間裡走來走去、來回踱。
- 日文：<span style="color:#2ECC71"><ruby>二人<rt>ふたり</rt></ruby>は</span><span style="color:#3498DB"><ruby>持<rt>も</rt></ruby>ちつ<ruby>持<rt>も</rt></ruby>たれつの<ruby>関係<rt>かんけい</rt></ruby>だ。</span>
  中文：兩人是互相扶持的關係。
