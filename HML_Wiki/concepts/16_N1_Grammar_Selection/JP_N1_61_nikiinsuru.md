# 〜に起因する

## 規則與接續
- `名詞 + に起因する`

## 用法說明
意為「起因於...」，書面用語，用於客觀說件、問題、現象的原因來源，常見於報告、新聞報導、學術論文，語感中性客觀，不帶個人情感色彩，與「〜のせいで」（帶負面歸咎語氣）形成對比。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71">この<ruby>事故<rt>じこ</rt></ruby>は</span><span style="color:#3498DB"><ruby>整備不良<rt>せいびふりょう</rt></ruby>に<ruby>起因<rt>きいん</rt></ruby>する。</span>
  中文：這起事故起因於保養不良。
- 日文：<span style="color:#2ECC71"><ruby>多<rt>おお</rt></ruby>くの<ruby>病気<rt>びょうき</rt></ruby>は</span><span style="color:#3498DB">ストレスに<ruby>起因<rt>きいん</rt></ruby>すると<ruby>言<rt>い</rt></ruby>われている。</span>
  中文：據說多疾病起因於壓力。
