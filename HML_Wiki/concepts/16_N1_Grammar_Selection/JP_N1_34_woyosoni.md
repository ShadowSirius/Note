# 〜をよそに

## 規則與接續
- `名詞 + をよそに`（多接「心配・反対・不安・期待」等情感／狀態名詞）

## 用法說明
意為「不顧、無視...的情況下」，表示對周遭的擔憂、反對、期待等視若無睹、逕自行動，常帶有批判色彩，主語常與被無視的對象不同（例：父母的擔心 vs 孩子的行動），與 [[JP_N1_33_mokamawazu|〜もかまわず @related_to]] 意義高度重疊，但「をよそに」更偏向「將他人的情緒或狀一旁」的疏離感。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E"><ruby>親<rt>おや</rt></ruby>の<ruby>心配<rt>しんぱい</rt></ruby>をよそに、</span><span style="color:#2ECC71"><ruby>息子<rt>むすこ</rt></ruby>は</span><span style="color:#3498DB"><ruby>一人旅<rt>ひとりたび</rt></ruby>に<ruby>出<rt>で</rt></ruby>た。</span>
  中文：不顧父母的擔心，兒子獨自出發旅行了。
- 日文：<span style="color:#FF477E"><ruby>周囲<rt>しゅうい</rt></ruby>の<ruby>反対<rt>はんたい</rt></ruby>をよそに、</span><span style="color:#2ECC71"><ruby>彼女<rt>かのじょ</rt></ruby>は</span><span style="color:#3498DB">その<ruby>計画<rt>けいかく</rt></ruby>を<ruby>進<rt>すす</rt></ruby>めた。</span>
  中文：不顧周圍的反對，她進了那個計畫。
