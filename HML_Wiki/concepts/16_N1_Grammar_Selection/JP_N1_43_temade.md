# 〜てまで

## 規則與接續
- `動詞て形 + まで`

## 用法說明
意為「甚至不惜...」，用於指出為達成某目的，不惜採取極端、甚至違反常理或犧牲重大代價的手段，多帶有質疑或批判語氣（是否值出如此代價），常見於反問句「〜てまで〜する必要があるのか」。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E"><ruby>借金<rt>しゃっきん</rt></ruby>をしてまで、</span><span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#3498DB">その<ruby>車<rt>くるま</rt></ruby>を<ruby>買<rt>か</rt></ruby>った。</span>
  中文：他甚至不惜借錢，也要買那輛車。
- 日文：<span style="color:#FF477E"><ruby>健康<rt>けんこう</rt></ruby>を<ruby>害<rt>がい</rt></ruby>してまで</span><span style="color:#3498DB"><ruby>働<rt>はたら</rt></ruby>く<ruby>必要<rt>ひつよう</rt></ruby>があるのだろうか。</span>
  中文：真的有必要不惜損害健康也要工作嗎
