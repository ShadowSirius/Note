# 〜べくもない

## 規則與接續
- `動詞辭書形 + べくもない`

## 用法說明
表示「不可能...、無從...」，強調客觀上完全沒有實現的可能性，帶有無奈、放棄的語感。與 [[JP_N1_02_beku|〜べく @related_to]] 同源，但「べくもない」是對該目的的徹底否定，常搭配「知る／望む／想像する」等動詞，書面語氣濃厚。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E"><ruby>当時<rt>とうじ</rt></ruby>の<ruby>状況<rt>じょうきょう</rt></ruby>を</span><span style="color:#3498DB"><ruby>今<rt>いま</rt></ruby>となっては<ruby>知<rt>し</rt></ruby>るべくもない。</span>
  中文：事到如今已無從得知當時的狀。
- 日文：<span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>が</span><span style="color:#3498DB"><ruby>成功<rt>せいこう</rt></ruby>するとは</span><span style="color:#FF477E"><ruby>誰<rt>だれ</rt></ruby>も</span><span style="color:#3498DB"><ruby>想像<rt>そうぞう</rt></ruby>すべくもなかった。</span>
  中文：誰也無從想像他會成功。
