# 〜はおろか

## 規則與接續
- `名詞 + はおろか + （名詞）+ も／さえ`

## 用法說明
意為「別說.連...也」，用於遞進式否定，先舉出一個程度較輕的事項並否定，再以「も／さえ」帶出程度更高、理應更容易達成卻同樣不成立的事項，語氣強烈、帶意外或誇張色彩，常見於強調事態嚴重性。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#FF477E"><ruby>英語<rt>えいご</rt></ruby>はおろか、</span><span style="color:#3498DB"><ruby>日本語<rt>にほんご</rt></ruby>さえ<ruby>満足<rt>まんぞく</rt></ruby>に<ruby>話<rt>はな</rt></ruby>せない。</span>
  中文：他別說文了，連日文都說好。
- 日文：<span style="color:#FF477E"><ruby>入院中<rt>にゅういんちゅう</rt></ruby>は</span><span style="color:#3498DB"><ruby>外出<rt>がいしゅつ</rt></ruby>はおろか、</span><span style="color:#2ECC71">ベッドから</span><span style="color:#3498DB"><ruby>起き上<rt>おきあ</rt></ruby>がることさえ<ruby>許<rt>ゆる</rt></ruby>されなかった。</span>
  中文：住院期間別說出了，連從床上起身都不被允許。
