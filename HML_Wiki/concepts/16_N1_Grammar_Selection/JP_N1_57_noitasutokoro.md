# 〜のいたすところ

## 規則與接續
- `名詞 + の + いたすところ`（多固定搭配「不徳の・力不足の・準備不足の」等自謙用詞）

## 用法說明
意為「都是...所致」，是極度謙遜、鄭重的自我歸因表現，常用於正式道歉、致辭場合，表示過錯或不理想的結果是自己某種不足（不徳、力不足等）所導致，帶自謙語氣。接續範圍高度慣用化，幾乎僅與固定的自謙詞搭配，日常會話不用。接續高度受限於「不徳」「力不足」「不注意」等固定自謙詞，不可自由替換為一般名詞，屬慣用度極高的固定表現。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E">これもひとえに</span><span style="color:#2ECC71"><ruby>私<rt>わたし</rt></ruby>の</span><span style="color:#3498DB"><ruby>不徳<rt>ふとく</rt></ruby>のいたすところです。</span>
  中文：這完全是我自己德不足所致。
- 日文：<span style="color:#2ECC71"><ruby>今回<rt>こんかい</rt></ruby>の<ruby>失敗<rt>しっぱい</rt></ruby>は、</span><span style="color:#FF477E"><ruby>私<rt>わたし</rt></ruby>の<ruby>準備不足<rt>じゅんびぶそく</rt></ruby>の</span><span style="color:#3498DB">いたすところです。</span>
  中文：這次的失敗，是我準備不足所致。
