# 〜であれ

## 規則與接續
- `名詞 + であれ`
- 疑問詞 + `であれ`（構成「何であれ／誰であれ／どこであれ」等全稱表現）

## 用法說明
文語條件／讓步，意為「無論是...」，常與疑問詞搭配構成「不論什麼情況都...」的全稱句，語氣鄭重、具論說色彩。也可單獨用於「たとえ〜であれ」構成假設讓步 [[JP_N1_13_dearouto|〜であろうと @related_to]] 意義相近，可互換，但「であれ」更常見於固定搭配與格言。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E"><ruby>理由<rt>りゆう</rt></ruby>が<ruby>何<rt>なん</rt></ruby>であれ、</span><span style="color:#3498DB"><ruby>暴力<rt>ぼうりょく</rt></ruby>は<ruby>許<rt>ゆる</rt></ruby>されない。</span>
  中文：無論理由是什麼，暴力都是不被允許的。
- 日文：<span style="color:#FF477E">どんな<ruby>結果<rt>けっか</rt></ruby>であれ、</span><span style="color:#2ECC71"><ruby>私<rt>わたし</rt></ruby>は</span><span style="color:#3498DB"><ruby>後悔<rt>こうかい</rt></ruby>しない。</span>
  中文：無論是什麼結果，我都不會後悔。
