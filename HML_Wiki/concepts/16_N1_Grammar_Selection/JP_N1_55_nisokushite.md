# 〜に即して

## 規則與接續
- `名詞 + に即して`（多接「事実・実情・現状・実態・時代」等具體事實／狀詞）
- 連體修飾時作「に即した」+ 名詞

## 用法說明
意為「依照、根據...（實際情況）」，強調緊貼著具體事實、實情或基準來判斷、處理，不脫現實，語感為「切合實際」。與 [[JP_N1_56_ninottotte|〜に則って @related_to]] 常被比較：「に即して」偏向「依照具體事實／現狀」，「に則って」偏向「遵循既定規則／傳統」，兩者接續對象不同。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

  中文：根據現狀，有必要重新檢討計畫。
- 日文：<span style="color:#FF477E"><ruby>事実<rt>じじつ</rt></ruby>に<ruby>即<rt>そく</rt></ruby>して、</span><span style="color:#3498DB"><ruby>判断<rt>はんだん</rt></ruby>すべきだ。</span>
  中文：應根據事實判斷。
