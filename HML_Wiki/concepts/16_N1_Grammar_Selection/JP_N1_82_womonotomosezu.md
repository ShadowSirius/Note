# 〜をものともせず

## 規則與接續
- `名詞 + をものともせず（に）`（多接「困難・逆境・批判・悪天候」等障礙、逆境類名詞）

## 用法說明
意為「不顧、不畏懼...」，表示不畏懼困難、逆境、障礙等，堅強地克服並前進，帶有積極、勇敢、正面評價的語感。與 [[JP_N1_34_woyosoni|〜をよそに @related_to]] 形成語感對比：「をものともせず」是正面稱讚的堅強不屈（克服困難），「をよそに」則多帶批判色彩（漠視他人的擔憂或反對）。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#FF477E"><ruby>周囲<rt>しゅうい</rt></ruby>の<ruby>批判<rt>ひはん</rt></ruby>をものともせず、</span><span style="color:#3498DB"><ruby>自分<rt>じぶん</rt></ruby>の<ruby>道<rt>みち</rt></ruby>を<ruby>貫<rt>つらぬ</rt></ruby>いた。</span>
  中文：他不畏周遭的批評，堅持走自己的路。
- 日文：<span style="color:#FF477E"><ruby>悪天候<rt>あくてんこう</rt></ruby>をものともせず、</span><span style="color:#3498DB"><ruby>登山<rt>とざん</rt></ruby>を<ruby>続<rt>つづ</rt></ruby>けた。</span>
  中文：不畏惡劣天候，繼續登山。
