# 〜てまいる

## 規則與接續
- `動詞て形 + まいる`

## 用法說明
「まいる（参る）」是「来る・行く」的謙讓語，「〜てまいる」表示自己的動作朝說、聽話者方向或某個目標謙遜地進行，亦可表示狀態隨時間逐漸變化的謙遜說如「寒くなってまいりました」），常見於正式致辭、商務場合的開場白或結語。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

  中文：今日，特此前來問候。
- 日文：<span style="color:#FF477E">だんだん</span><span style="color:#3498DB"><ruby>寒<rt>さむ</rt></ruby>くなってまいりました。</span>
  中文：天氣漸漸變冷了。
