# 〜に足る

## 規則與接續
- `動詞辭書形・名詞 + に足る + 名詞`
- 句尾用法：`〜に足る` / `〜に足りない`（否定）

## 用法說明
意為「足以...、值..」，用於評價某人事物具備充分的資格或價值承受某種評價或信任，語氣正面、書面色彩濃厚，常見於「信頼するに足る」「尊敬するに足る」等固定搭配。與 [[JP_N1_47_nitaeru|〜に堪える @related_to]] 意義相近，皆表「值經得起」，但「に足る」偏重「資格充分」，「に堪える」偏重「承受得住考驗」。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

  中文：他是值信賴人物。

  中文：那個提案是值考慮的內。
