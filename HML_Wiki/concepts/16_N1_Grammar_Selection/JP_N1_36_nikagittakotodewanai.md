# 〜に限ったことではない

## 規則與接續
- `名詞 + に限ったことではない`

## 用法說明
意為「不僅限於...」，用於指出某問題或現象並非只發生於特定對象／時間，而是普遍存在的情況，語氣帶有補充說、糾正過於狹隘看法的意味，常見於評論、討論文脈。與 [[JP_N1_44_nitodomarazu|〜にとどまらず @related_to]] 意義相近，皆表「不僅限於」，但「に限ったことではない」更口語化、常用於反駁「這只是個案」的說

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

  中文：這個問題不僅限於日本。
- 日文：<span style="color:#FF477E">こうしたトラブルは</span><span style="color:#2ECC71"><ruby>今回<rt>こんかい</rt></ruby>に</span><span style="color:#3498DB"><ruby>限<rt>かぎ</rt></ruby>ったことではない。</span>
  中文：這樣的糾紛不僅限於這一次。
