# 〜いかんでは

## 規則與接續
- `名詞 + の + いかんでは`
- `名詞 + いかんでは`

## 用法說明
意為「依...而定」，表示後項的結果或處置會根據前項的具體狀而有所不同，帶有「視情況決定」的條件語感，屬書面正式用語。與 [[JP_N1_79_ikanniyorazu|〜いかんによらず @related_to]] 恰為對照組：「いかんでは」表示「視情況而定、會受影響」，「いかんによらず」表示「不管情況如何、不受影響」。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E"><ruby>天候<rt>てんこう</rt></ruby>のいかんでは、</span><span style="color:#2ECC71"><ruby>試合<rt>しあい</rt></ruby>は</span><span style="color:#3498DB"><ruby>中止<rt>ちゅうし</rt></ruby>になるかもしれない。</span>
  中文：視天氣狀而定，比賽可能會中止。
- 日文：<span style="color:#FF477E"><ruby>結果<rt>けっか</rt></ruby>いかんでは、</span><span style="color:#3498DB"><ruby>計画<rt>けいかく</rt></ruby>を<ruby>見直<rt>みなお</rt></ruby>すことになる。</span>
  中文：視結果而定，可能會重新檢討計畫。
