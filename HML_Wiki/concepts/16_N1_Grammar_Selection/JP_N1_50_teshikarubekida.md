# 〜てしかるべきだ

## 規則與接續
- `動詞て形 + しかるべきだ`

## 用法說明
意為「理應...才對」，用於主張某事本應如此、按常理或道義應當發生，帶有評論者的價值斷與略帶不滿（暗示現實並非如此）的語氣，常見於評論文章對現狀的批評性建議。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E">これほどの<ruby>功績<rt>こうせき</rt></ruby>なら</span><span style="color:#2ECC71">もっと</span><span style="color:#3498DB"><ruby>評価<rt>ひょうか</rt></ruby>されてしかるべきだ。</span>
  中文：這樣的功績理應得到更高的評價才對。
- 日文：<span style="color:#FF477E"><ruby>被害者<rt>ひがいしゃ</rt></ruby>には</span><span style="color:#2ECC71"><ruby>十分<rt>じゅうぶん</rt></ruby>な</span><span style="color:#3498DB"><ruby>補償<rt>ほしょう</rt></ruby>がなされてしかるべきだ。</span>
  中文：對受害者理應給予充分的補償才對。
