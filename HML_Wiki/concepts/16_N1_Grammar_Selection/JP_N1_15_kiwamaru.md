# 〜極まる

## 規則與接續
- `な形容詞語幹 + 極まる`

## 用法說明
與 [[JP_N1_14_kiwamarinai|〜極まりない @related_to]] 同義，皆表「...到極點」，差別在「極まる」是動詞用法（原意「達到極限」），可直接修飾名詞（例：極まる態度），書面強調語氣略高於「極まりない」，兩者實務上可互換使用。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71"><ruby>彼<rt>か</rt></ruby>の</span><span style="color:#3498DB"><ruby>行動<rt>こうどう</rt></ruby>は</span><span style="color:#FF477E"><ruby>無責任<rt>むせきにん</rt></ruby><ruby>極<rt>きわ</rt></ruby>まる</span><span style="color:#3498DB">ものだった。</span>
  中文：他的行動是極其不負責任的。
- 日文：<span style="color:#FF477E">その<ruby>判断<rt>はんだん</rt></ruby>は</span><span style="color:#3498DB"><ruby>愚<rt>おろ</rt></ruby>か<ruby>極<rt>きわ</rt></ruby>まる。</span>
  中文：那個判斷愚蠢至極。
