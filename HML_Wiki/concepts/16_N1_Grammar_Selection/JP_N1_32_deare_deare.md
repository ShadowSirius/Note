# 〜であれ〜であれ

## 規則與接續
- `名詞A + であれ + 名詞B + であれ`

## 用法說明
[[JP_N1_12_deare|〜であれ @related_to]] 的並列疊用形式，意為「無論是...還是...」，用於列舉兩個（或以上）對立或並列的選項，表示不論哪種情況結論都相同，語感鄭重、常見於論說的條件列舉。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E"><ruby>男<rt>おとこ</rt></ruby>であれ<ruby>女<rt>おんな</rt></ruby>であれ、</span><span style="color:#2ECC71"><ruby>能力<rt>のうりょく</rt></ruby>があれば</span><span style="color:#3498DB"><ruby>採用<rt>さいよう</rt></ruby>される。</span>
  中文：無論是男是女，只要有能力就會被錄。
- 日文：<span style="color:#FF477E"><ruby>賛成<rt>さんせい</rt></ruby>であれ<ruby>反対<rt>はんたい</rt></ruby>であれ、</span><span style="color:#2ECC71"><ruby>意見<rt>いけん</rt></ruby>は</span><span style="color:#3498DB"><ruby>尊重<rt>そんちょう</rt></ruby>されるべきだ。</span>
  中文：無論贊成還是反對，意見都應該被尊重。
