# 〜とばかりに

## 規則與接續
- `普通形・引用句 + とばかりに`

## 用法說明
意為「幾乎要說...似地」，用於描寫某人雖未明說但其態度、動作彷彿在表達某句話，常見於生動的敘事描寫，與 [[JP_N1_05_nbakarini|〜んばかりに @related_to]] 結構功能相近，但「とばかりに」前面接的是「像是要說話」（引用句形式），而「んばかりに」接的是動作或狀態本身。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#3498DB">「もう<ruby>限界<rt>げんかい</rt></ruby>だ」とばかりに</span><span style="color:#FF477E"><ruby>椅子<rt>いす</rt></ruby>に<ruby>座<rt>すわ</rt></ruby>り<ruby>込<rt>こ</rt></ruby>んだ。</span>
  中文：他一副「已經到極限了」似地一屁股坐了下去。
- 日文：<span style="color:#2ECC71"><ruby>彼女<rt>かのじょ</rt></ruby>は</span><span style="color:#3498DB">「チャンス<ruby>到来<rt>とうらい</rt></ruby>」とばかりに</span><span style="color:#FF477E">その<ruby>提案<rt>ていあん</rt></ruby>に<ruby>飛<rt>と</rt></ruby>びついた。</span>
  中文：她副「機會來了」似地立刻抓住了那個提案。
