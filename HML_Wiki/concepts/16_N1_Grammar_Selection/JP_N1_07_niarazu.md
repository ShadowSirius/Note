# 〜にあらず

## 規則與接續
- `名詞 + にあらず`
- `動詞・形容詞普通形 + にあらず`（較少見，多接名詞）

## 用法說明
文語否定表現，等同「〜ではない」，意為「並非是...」，常見於格言、標語、書面評論，帶有斷然否定的鄭重語氣。常與「〜にして」「〜こそ」等文語搭配構成對句，日常會話完全不用。文法上是文語判斷助動詞「なり」的連用形否定「にあらず」（なり→に＋あらず，「あり」的否定即「あらず」），故僅接於名詞後，不可直接接動詞、形容詞普通形。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71">これは</span><span style="color:#3498DB"><ruby>単<rt>たん</rt></ruby>なる<ruby>偶然<rt>ぐうぜん</rt></ruby>にあらず。</span>
  中文：這並非單純的偶然。
- 日文：<span style="color:#2ECC71"><ruby>人<rt>にん</rt></ruby>は</span><span style="color:#3498DB">パンのみにて<ruby>生<rt>い</rt></ruby>くる<ruby>者<rt>もの</rt></ruby>にあらず。</span>
  中文：人不是只靠麵包過活的。
- 日文：<span style="color:#2ECC71"><ruby>彼<rt>か</rt></ruby>の<ruby>行動<rt>こうどう</rt></ruby>は</span><span style="color:#3498DB"><ruby>偶然<rt>ぐうぜん</rt></ruby>にあらず、</span><span style="color:#FF477E"><ruby>綿密<rt>めんみつ</rt></ruby>な<ruby>計算<rt>けいさん</rt></ruby>の<ruby>結果<rt>けっか</rt></ruby>である。</span>
  中文：他的行動並非偶然，而是縝計算的結果。
