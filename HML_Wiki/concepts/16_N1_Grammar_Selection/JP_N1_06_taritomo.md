# 〜たりとも〜ない

## 規則與接續
- `數量詞（一瞬・一日・一円等） + たりとも + 〜ない`

## 用法說明
表示「即使...也不、一...都不」，用於強調極端最小單位（一瞬間、一天、一分錢等）都完全否定，語氣強烈、鄭重，常見於誓言、警語、正式演說口語「〜も〜ない」相比，「たりとも」限定接「一」開頭的數量詞，且文語感濃厚，不用於日常對話。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E">この<ruby>秘密<rt>ひみつ</rt></ruby>は</span><span style="color:#FF477E"><ruby>一瞬<rt>いっしゅん</rt></ruby>（いっしゅん）たりとも</span><span style="color:#3498DB"><ruby>忘<rt>わす</rt></ruby>れたことはない。</span>
  中文：這個秘密我一瞬間都不曾忘記過。
- 日文：<span style="color:#FF477E"><ruby>税金<rt>ぜいきん</rt></ruby>は</span><span style="color:#FF477E"><ruby>一円<rt>いちえん</rt></ruby>たりとも</span><span style="color:#3498DB">ごまかすことは<ruby>許<rt>ゆる</rt></ruby>されない。</span>
  中文：税金一分錢都不允許矇混。
