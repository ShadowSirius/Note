# 高頻詞彙 13：時間表現深化（〜に規則・順序詞・時間帶）

本卡化 [[JP_Vocab_03_time_numbers|時間與數量 @extends]] 中已收的基礎時間詞（今日/昨日/明日/朝/昼/夜/午前/午後/今週/先週/来週等），**不重複建立基礎詞表**，聚焦三件事：〜に 該不該加的判斷規則、順序／連接類時間詞的細緻辨義、以及一日與距今遠近的時間帶系統。

## 🧠 記憶鉤
- **〜に 加不加，看「有沒有數字釘住一個點」**：三時・7月10日・2020年 都是可以用手指在日曆鐘上戳出來的「點」，點才需要 に 釘住住今日・明日・毎朝 這種相對詞本身已經指向明確的一天，不需要再釘。
- **この間・この頃・この前 三兄弟，用「時間箭頭方向」記**：この間間箭頭指向過去某一點（前幾天發生的事，一次性））この頃頃箭頭指向現在，是一段持續到現在的區間（最近這陣子））この前前箭頭指向過去某次事件（上一次，可重複發生的事件中的最近一次，如上次見面）。
- **さらいしゅう・さらいねん 的「さ」」 再**：再来週・再来年 是「來＋再來一次」」未來 +2 +2一昨日・一昨年 是「昨＋再往前一次」」過去 -2。「來」的加倍用「再」，「昨」的加倍用「一」，兩條路線用字完全不同，不要混著猜。
- **これから／それから／そして 用「時間軸位置」分**：これからこれから從現在這一刻起（面向未來，常單獨開頭發語））それからそれから從剛講完的動作之後接下一個動作（強調先後順序，可替換成「その後」）そしてそして單純並列/添加下一件事（順序感較弱，也可表「而且」）。口訣：「これ」是現在,「それ」是剛剛講的那件事。

## 📅 相對日／週／年系統對照表
| 距今 | −2 | −1 | 0 | +1 | +2 |
|---|---|---|---|---|---|
| 日 | 一昨日（おととい） | 昨日（きのう） | 今日（きょう） | 明日（あした／あす） | 明後日（あさって） |
| （日，極端） | | | | | 明明後日（しあさって，+3） |
| 週 | ─ | 先週（せんしゅう） | 今週（こんしゅう） | 来週（らいしゅう） | 再来週（さらいしゅう） |
| 年 | 一昨年（おととし） | 去年（きょねん） | 今年（ことし） | 来年（らいねん） | 再来年（さらいねん） |

- 日/昨/明 已收於 [[JP_Vocab_03_time_numbers]]（今日・昨日・明日））本表新增昨日、明後日、明明後日、再来週、一昨年、再来年。
- **「さ・らい規律」記憶鉤**：週與年系統呈規則對稱——未來 +1 用「来」，+2 在「来」前加「再」（さ）變成「再来」」過去 −1 用「先/去」，−2 用「一昨」。日系統則完全不遵循此規律，是獨立的一組固有詞（一昨日・明後日・明明後日），不能套用「再＋来日」去猜。
