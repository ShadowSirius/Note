# 〜くせして

## 規則與接續
- `動詞・形容詞普通形 + くせして`
- `名詞・な形容詞語幹 + の + くせして`

## 用法說明
表示「明明...卻...」，比「くせに」更口語、更帶輕蔑或挖氣，常用於朋友間半開玩笑地吐槽對方言行不一致。不適用於正式或對長輩使用。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71"><ruby>子供<rt>こども</rt></ruby>の</span><span style="color:#FF477E">くせして、</span><span style="color:#3498DB">えらそうなことを<ruby>言<rt>い</rt></ruby>うな。</span>
  中文：明明是小孩，別說那麼了不起。
- 日文：<span style="color:#2ECC71"><ruby>下手<rt>へた</rt></ruby>な</span><span style="color:#FF477E">くせして、</span><span style="color:#3498DB">いつも<ruby>自信<rt>じしん</rt></ruby><ruby>満<rt>まん</rt></ruby>だ。</span>
  中文：明明技術很差，卻總是自信滿滿。
