# 〜がてら

## 規則與接續
- `動詞ます形 + がてら`
- `名詞 + がてら`

## 用法說明
表示「順便...」，指在做前項這個主要動作的同時，利用同一段時間或路程順道完成後項的另事，兩個動作共用同一個移動或行動過程。語感比「ついでに」更書面、文雅，常見於散步、購物等日常移動場合。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF9F1C"><ruby>散歩<rt>さんぽ</rt></ruby>がてら、</span><span style="color:#3498DB">コンビニに<ruby>寄<rt>よ</rt></ruby>った。</span>
  中文：散步順便去了一趟利商店。
- 日文：<span style="color:#FF9F1C"><ruby>買い物<rt>かいもの</rt></ruby>がてら、</span><span style="color:#3498DB"><ruby>友達<rt>ともだち</rt></ruby>の<ruby>家<rt>いえ</rt></ruby>に<ruby>寄<rt>よ</rt></ruby>ってみよう。</span>
  中文：買東西的時候順便去朋友家看看吧
