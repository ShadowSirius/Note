# 〜に基づいて

## 規則與接續
- `名詞 + に基づいて／に基づき／に基づいた + 名詞`

## 用法說明
表示「基於...、根據...」，強調後項的判斷、行動或作品是以前項作為依循的準則或根據，語氣正式客觀，常見於法律條文、學術論文、新聞報導。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71">この<ruby>映画<rt>えいが</rt></ruby>は</span><span style="color:#FF477E"><ruby>事実<rt>じじつ</rt></ruby>に<ruby>基<rt>もと</rt></ruby>づいて</span><span style="color:#3498DB"><ruby>作<rt>つく</rt></ruby>られている。</span>
  中文：這部電影是根據事實所拍攝的。
- 日文：<span style="color:#2ECC71"><ruby>法律<rt>ほうりつ</rt></ruby>に</span><span style="color:#FF477E"><ruby>基<rt>もと</rt></ruby>づいて、</span><span style="color:#3498DB"><ruby>処罰<rt>しょばつ</rt></ruby>される。</span>
  中文：將依照法律受到懲處。
