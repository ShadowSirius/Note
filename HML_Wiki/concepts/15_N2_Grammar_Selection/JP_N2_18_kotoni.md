# 〜ことに

## 規則與接續
- `動詞た形 / い形容詞 + ことに`
- `な形容詞語幹 + な + ことに`

## 用法說明
表示「令人...的是」，置於句首，先表達說對後述事實的感嘆或評論，常見詞如「驚いたことに」「残念なことに」。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E"><ruby>驚<rt>おどろ</rt></ruby>いたことに、</span><span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#3498DB">たった<ruby>一年<rt>いちねん</rt></ruby>で<ruby>日本語<rt>にほんご</rt></ruby>をマスターした。</span>
  中文：令人驚訝的是，他僅僅一年就精通了日文。
- 日文：<span style="color:#FF477E"><ruby>残念<rt>ざんねん</rt></ruby>なことに、</span><span style="color:#3498DB"><ruby>今年<rt>ことし</rt></ruby>の<ruby>花見<rt>はなみ</rt></ruby>は<ruby>中止<rt>ちゅうし</rt></ruby>になった。</span>
  中文：很遺憾的是，今年的賞花活動取消了。
