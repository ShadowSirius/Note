# 〜手前

## 規則與接續
- `動詞普通形・た形 + 手前`
- `名詞の + 手前`

## 用法說明
表示「由於立場、面子所迫，不得不...」，強調因為顧慮自己曾說的話或所處立場，不好意思／不能不做後項動作，帶有拉不下臉、礙於情面的語感。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71"><ruby>部下<rt>ぶか</rt></ruby>の</span><span style="color:#FF477E"><ruby>手前<rt>てまえ</rt></ruby>、</span><span style="color:#3498DB"><ruby>弱音<rt>よわね</rt></ruby><ruby>吐<rt>は</rt></ruby>けない。</span>
  中文：礙於下屬在場，不好意思說氣話。
- 日文：<span style="color:#2ECC71"><ruby>子供<rt>こども</rt></ruby>に</span><span style="color:#FF477E"><ruby>約束<rt>やくそく</rt></ruby>した</span><span style="color:#3498DB"><ruby>手前<rt>てまえ</rt></ruby>、<ruby>今更<rt>いまさら</rt></ruby>やめるとは<ruby>言<rt>い</rt></ruby>えない。</span>
  中文：因為已經跟孩子約好了，事到如今也不能說做了。
