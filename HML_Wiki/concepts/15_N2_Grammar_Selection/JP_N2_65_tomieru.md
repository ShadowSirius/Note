# 〜とみえる

## 規則與接續
- `動詞・形容詞普通形 + とみえる`
- `な形容詞語幹／名詞 + だとみえる`

## 用法說明
表示「看來是...」，依據觀察到的具體線索或客觀狀做出的推測，語氣較客觀、留有餘地，並非說主觀臆測。常可與「らしい」「ようだ」互換，但「とみえる」更強調「從眼前的證據看來」的推論過程。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71"><ruby>道<rt>みち</rt></ruby>が</span><span style="color:#3498DB"><ruby>濡<rt>ぬ</rt></ruby>れている。</span><span style="color:#FF9F1C"><ruby>夜<rt>よる</rt></ruby>のうちに</span><span style="color:#3498DB"><ruby>雨<rt>あめ</rt></ruby>が<ruby>降<rt>ふ</rt></ruby>ったとみえる。</span>
  中文：路是濕的。看來是晚下過雨了。
- 日文：<span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#3498DB"><ruby>疲<rt>つか</rt></ruby>れているとみえて、</span><span style="color:#FF477E"><ruby>話<rt>はな</rt></ruby>しかけても</span><span style="color:#3498DB"><ruby>上<rt>うえ</rt></ruby>の<ruby>空<rt>そら</rt></ruby>だった。</span>
  中文：他看起來很累，跟他說也心不在焉。
