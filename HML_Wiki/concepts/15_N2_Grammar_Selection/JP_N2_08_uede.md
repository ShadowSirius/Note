# 〜上で

## 規則與接續
- `動詞た形 + 上で`（先做...再...）
- `名詞の + 上で`（在...方面）

## 用法說明
兩種主要用法：①「動詞た形＋上で」表示先完成前項步，才進行後項動作，強調先後順序順序②「名詞の＋上で」表示在某個層面、方面上（如仕事の上で、生活の上で）。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E"><ruby>資料<rt>しりょう</rt></ruby>をよく<ruby>読<rt>よ</rt></ruby>んだ<ruby>上<rt>うえ</rt></ruby>で、</span><span style="color:#3498DB"><ruby>意見<rt>いけん</rt></ruby>を<ruby>述<rt>の</rt></ruby>べてください。</span>
  中文：請仔細看過資料之後，再發表意見。
- 日文：<span style="color:#2ECC71">それは</span><span style="color:#FF477E"><ruby>仕事<rt>しごと</rt></ruby>の<ruby>上<rt>うえ</rt></ruby>で、</span><span style="color:#3498DB">とても<ruby>大切<rt>たいせつ</rt></ruby>なことだ。</span>
  中文：那在工作方面來說非常重要的事。
