# 〜限りだ

## 規則與接續
- `い形容詞普通形（現在形） + 限りだ`
- `な形容詞語幹 + な + 限りだ`

## 用法說明
表示「真是非常...」，用來表達說當下極端強烈的個人感受，多接感情形容詞（うれしい、心細い、羨ましい、残念だ等），帶有主觀誇張的語氣，僅限第一人稱視角使用，不可用於描述他人的感受。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

  中文：一個人住在國外，真是非常不安。
- 日文：<span style="color:#2ECC71"><ruby>息子<rt>むすこ</rt></ruby>が</span><span style="color:#FF9F1C"><ruby>第一<rt>だいいち</rt></ruby><ruby>志望<rt>しぼう</rt></ruby>に<ruby>合格<rt>ごうかく</rt></ruby>して、</span><span style="color:#3498DB">うれしい<ruby>限<rt>かぎ</rt></ruby>りだ。</span>
  中文：兒子考上第一志願，真是太高興了。
