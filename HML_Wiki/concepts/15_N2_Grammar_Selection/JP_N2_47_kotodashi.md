# 〜ことだし

## 規則與接續
- `用言普通形 + ことだし`
- `名詞・な形容詞語幹 + な／である + ことだし`

## 用法說明
表示「既然...（就順便）...」，列舉一個理由，說既然情況如此，就順勢做出後項的決定，語氣輕鬆、口語，帶有「剛好、順便」的意味，常用於提議或說個人決定的理由。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#E67E22"><ruby>天気<rt>てんき</rt></ruby>もいい</span><span style="color:#FF477E">ことだし、</span><span style="color:#3498DB"><ruby>散歩<rt>さんぽ</rt></ruby>にでも<ruby>行<rt>い</rt></ruby>こうか。</span>
  中文：天氣也不錯，要不要順便去散個步。
- 日文：<span style="color:#E67E22">もう<ruby>遅<rt>おそ</rt></ruby>い</span><span style="color:#FF477E">ことだし、</span><span style="color:#3498DB"><ruby>今日<rt>こんにち</rt></ruby>はこれで<ruby>失礼<rt>しつれい</rt></ruby>します。</span>
  中文：時間也不早了，今天就先告辭了。
