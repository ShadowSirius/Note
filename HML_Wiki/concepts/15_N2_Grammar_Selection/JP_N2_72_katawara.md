# 〜かたわら

## 規則與接續
- `動詞辞書形 + かたわら`
- `名詞 + の + かたわら`

## 用法說明
表示「一邊...一邊（從事另件事）」，指以前項為本業或主要活動，同時長期進行後項的另項活動（多為兼職、副業、興趣），強調兩者並行持續一段時間的狀態，語氣書面、正式，常見於介紹人物經歷

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#FF9F1C"><ruby>会社<rt>かいしゃ</rt></ruby><ruby>勤<rt>つと</rt></ruby>めのかたわら、</span><span style="color:#3498DB"><ruby>小説<rt>しょうせつ</rt></ruby>を<ruby>書<rt>か</rt></ruby>いている。</span>
  中文：他一邊在公司上班，一邊寫小說
- 日文：<span style="color:#FF9F1C"><ruby>育児<rt>いくじ</rt></ruby>のかたわら、</span><span style="color:#3498DB"><ruby>大学院<rt>だいがくいん</rt></ruby>で<ruby>研究<rt>けんきゅう</rt></ruby>を<ruby>続<rt>つづ</rt></ruby>けている。</span>
  中文：一邊育兒，一邊在研究所持續做研究。
