# 〜につれて

## 規則與接續
- `動詞辞書形 / 名詞 + につれて`

## 用法說明
表示「隨著...」，指兩個事物同步生變化，前項變化，後項也隨之改變，語氣較自然、不特別強調書面性，與 [[JP_N2_30_nitomonatte|〜に伴って @related_to]] 意義相近但更常用於自然漸進的變化。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E"><ruby>時間<rt>じかん</rt></ruby>が<ruby>経<rt>へ</rt></ruby>つにつれて、</span><span style="color:#3498DB"><ruby>悲<rt>かな</rt></ruby>しみは<ruby>薄<rt>うす</rt></ruby>らいでいった。</span>
  中文：隨著時間過去，悲傷漸漸淡去了。
- 日文：<span style="color:#FF477E"><ruby>年齢<rt>ねんれい</rt></ruby>が<ruby>上<rt>あ</rt></ruby>がるにつれて、</span><span style="color:#3498DB"><ruby>体力<rt>たいりょく</rt></ruby>が<ruby>落<rt>お</rt></ruby>ちてくる。</span>
  中文：隨著年齡增，體力會逐漸下降。
