# 〜どころではない

## 規則與接續
- `名詞 + どころではない`
- `動詞辞書形 + どころではない`

## 用法說明
表示「哪還能...、根本不是...的時候」，因為忙碌、危急、經濟困難等狀，說者完全沒有餘裕去做前項所說事，帶有強烈的否定與無奈語氣，常用於解釋為何無法做某事。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF9F1C"><ruby>締め切<rt>しめき</rt></ruby>りが<ruby>近<rt>ちか</rt></ruby>くて、</span><span style="color:#3498DB"><ruby>旅行<rt>りょこう</rt></ruby>どころではない。</span>
  中文：截止日期快到了，哪空去旅行。
- 日文：<span style="color:#FF9F1C"><ruby>台風<rt>たいふう</rt></ruby>で</span><span style="color:#2ECC71"><ruby>電車<rt>でんしゃ</rt></ruby>が</span><span style="color:#3498DB"><ruby>止<rt>ど</rt></ruby>まり、<ruby>会議<rt>かいぎ</rt></ruby>どころではなくなった。</span>
  中文：颱風導致電車停駛，根本沒辦開會了。
