# 〜ことなしに

## 規則與接續
- `動詞辞書形 + ことなしに`
- 固定句型：`〜ことなしには〜ない`（沒有...就不能...）

## 用法說明
書面語，表示「不...地、沒有...的情況下」，強調未經過某個動作或條件就直接進行後項，語氣生硬正式，多用於評論、論說與「〜ことなく」意思相近，但「ことなしに」更強調「若不經過該步的條件性。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71"><ruby>努力<rt>どりょく</rt></ruby>する</span><span style="color:#FF477E">ことなしに、</span><span style="color:#3498DB"><ruby>成功<rt>せいこう</rt></ruby>を<ruby>手に入<rt>てにい</rt></ruby>れることはできない。</span>
  中文：不努力就無法獲得成功。
- 日文：<span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#FF477E"><ruby>誰<rt>だれ</rt></ruby>にも<ruby>相談<rt>そうだん</rt></ruby>することなしに、</span><span style="color:#3498DB"><ruby>会社<rt>かいしゃ</rt></ruby>を<ruby>辞<rt>や</rt></ruby>めた。</span>
  中文：他沒有跟任何人商量就辭掉了公司。
