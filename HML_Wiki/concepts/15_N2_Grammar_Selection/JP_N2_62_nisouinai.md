# 〜に相違ない

## 規則與接續
- `動詞・形容詞普通形 + に相違ない`
- `な形容詞語幹／名詞 + に相違ない`

## 用法說明
表示「一定是...、必定是...」，說依據客觀根據做出強烈的斷定推測。語氣比「に違いない」更書面、正式，常見於新聞報導、鑑定報告、推理小說合，帶有不容置疑的確信感。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF9F1C"><ruby>彼<rt>か</rt></ruby>の<ruby>話し方<rt>はなしかた</rt></ruby>から<ruby>見<rt>み</rt></ruby>て、</span><span style="color:#2ECC71">この<ruby>人<rt>にん</rt></ruby>は</span><span style="color:#3498DB"><ruby>関西出身<rt>かんさいしゅっしん</rt></ruby>に<ruby>相違<rt>そうい</rt></ruby>ない。</span>
  中文：從他的說方式來看，這個人肯定是關西出身。
- 日文：<span style="color:#FF477E"><ruby>現場<rt>げんば</rt></ruby>に<ruby>残<rt>のこ</rt></ruby>された<ruby>指紋<rt>しもん</rt></ruby>から、</span><span style="color:#2ECC71"><ruby>犯人<rt>はんにん</rt></ruby>は</span><span style="color:#3498DB">この<ruby>部屋<rt>へや</rt></ruby>に<ruby>入<rt>いっ</rt></ruby>ったに<ruby>相違<rt>そうい</rt></ruby>ない。</span>
  中文：從現場留下的指紋來看，犯人肯定進過這個房間。
