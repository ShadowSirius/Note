# 〜まいと

## 規則與接續
- `動詞辞書形 + まいと（する／思う）`
- `一段動詞・する・来る` 另 `まい` 特殊形（例：見まい、するまい／すまい、来まい／来まい）

## 用法說明
表示「打算不要...、抱著不做...的心態」，是「〜ないようにと」的書面說帶有主動抗拒、努力壓抑某行為的意志，常見於描寫內的文學語句。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#FF477E"><ruby>涙<rt>なみだ</rt></ruby>を<ruby>見<rt>み</rt></ruby>せまいと、</span><span style="color:#3498DB"><ruby>必死<rt>ひっし</rt></ruby>に<ruby>耐<rt>た</rt></ruby>えた。</span>
  中文：他拚忍耐，不想讓人看見自己的眼淚。
- 日文：<span style="color:#2ECC71"><ruby>二度<rt>にど</rt></ruby>と</span><span style="color:#FF477E"><ruby>同<rt>おな</rt></ruby>じ<ruby>失敗<rt>しっぱい</rt></ruby>を<ruby>繰り返<rt>くりかえ</rt></ruby>すまいと、</span><span style="color:#3498DB"><ruby>心<rt>こころ</rt></ruby>に<ruby>誓<rt>ちか</rt></ruby>った。</span>
  中文：他下定決心，發誓不再重蹈覆轍。
