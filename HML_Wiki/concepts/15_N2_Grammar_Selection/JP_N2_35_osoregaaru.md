# 〜恐れがある

## 規則與接續
- `動詞辞書形 + 恐れがある`
- `名詞の + 恐れがある`

## 用法說明
表示「恐怕會...、有...的疑慮」，是帶負面風險的正式書面推測，常見於新聞、氣象預報、公告等場合，用來客觀陳述潛在危險或不良後果的可能性，不用於日常口語小事。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#E67E22"><ruby>今夜<rt>こんや</rt></ruby>から<ruby>明日<rt>あした</rt></ruby>にかけて、</span><span style="color:#2ECC71"><ruby>大雨<rt>おおあめ</rt></ruby>により</span><span style="color:#3498DB"><ruby>川<rt>かわ</rt></ruby>が<ruby>氾濫<rt>はんらん</rt></ruby>する<ruby>恐<rt>おそ</rt></ruby>れがある。</span>
  中文：從今晚明天，可能因大雨導致河川氾濫。
- 日文：<span style="color:#2ECC71">この<ruby>薬<rt>くすり</rt></ruby>は</span><span style="color:#3498DB"><ruby>副作用<rt>ふくさよう</rt></ruby>を<ruby>引き起<rt>ひきお</rt></ruby>こす<ruby>恐<rt>おそ</rt></ruby>れがある。</span>
  中文：這種藥恐怕會引起副作用。
