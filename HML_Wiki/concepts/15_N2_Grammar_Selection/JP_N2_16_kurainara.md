# 〜くらいなら

## 規則與接續
- `動詞辞書形 + くらいなら`

## 用法說明
表示「與其...倒不如...」，用來比較兩個都不理想的選項，說者認為後項（通常也不理想）比前項還要好一些，帶有強烈的抗拒語氣。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E">あの<ruby>人<rt>にん</rt></ruby>に<ruby>頭<rt>あたま</rt></ruby>を<ruby>下<rt>さ</rt></ruby>げるくらいなら、</span><span style="color:#3498DB"><ruby>死<rt>し</rt></ruby>んだ<ruby>方<rt>ほう</rt></ruby>がましだ。</span>
  中文：與其向那個人低頭，倒不如死了算了。
- 日文：<span style="color:#FF477E"><ruby>残業<rt>ざんぎょう</rt></ruby>するくらいなら、</span><span style="color:#3498DB"><ruby>会社<rt>かいしゃ</rt></ruby>を<ruby>辞<rt>や</rt></ruby>めたい。</span>
  中文：與其加班，我倒想辭職。
