# 〜ぶり

## 規則與接續
- `時間名詞 + ぶり`（表示「闊別...、相隔...」）
- `動詞ます形 + ぶり`（表示「...的樣子、方式」，如 話し方話し方話しぶり）

## 用法說明
有兩種常見用法：①接時間名詞，表示「闊別...、相隔...」，強調距離上次發生已經過了一段時間才再度發生發生②接動詞ます形，表示「...的樣子、方式」（話しぶりぶり說樣子、飲みっぷりっぷり喝酒的豪爽程度），描述做某動作時所展現的風格或態度。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

  中文：闊別十年回到了故鄉
- 日文：<span style="color:#2ECC71"><ruby>彼<rt>か</rt></ruby>の</span><span style="color:#FF9F1C"><ruby>話<rt>はな</rt></ruby>しぶりから、</span><span style="color:#3498DB"><ruby>自信<rt>じしん</rt></ruby>があるのがわかる。</span>
  中文：從他的說方式可以看出他很有自信。
