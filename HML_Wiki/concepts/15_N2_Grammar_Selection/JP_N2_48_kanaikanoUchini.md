# 〜か〜ないかのうちに

## 規則與接續
- `動詞辞書形A + か + 動詞ないA形 + かのうちに`（同一動詞肯定形與否定形並列）

## 用法說明
表示「剛...就馬上...」，強調前項動作幾乎與後項動作同時發生，時間極短，帶有「說遲那時快」的臨場感，常用於描寫連續發生的動作。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71">ベルが</span><span style="color:#FF477E"><ruby>鳴<rt>な</rt></ruby>るか<ruby>鳴<rt>な</rt></ruby>らないかのうちに、</span><span style="color:#3498DB"><ruby>子供<rt>こども</rt></ruby>たちは<ruby>教室<rt>きょうしつ</rt></ruby>を<ruby>飛び出<rt>とびだ</rt></ruby>した。</span>
  中文：鈴聲才剛響，孩子們就衝出了教室。
- 日文：<span style="color:#2ECC71"><ruby>試合<rt>しあい</rt></ruby>が</span><span style="color:#FF477E"><ruby>始<rt>はじ</rt></ruby>まるか<ruby>始<rt>はじ</rt></ruby>まらないかのうちに、</span><span style="color:#3498DB"><ruby>雨<rt>あめ</rt></ruby>が<ruby>降<rt>お</rt></ruby>り<ruby>出<rt>だ</rt></ruby>した。</span>
  中文：比賽才剛開始，就下起了雨。
