# 〜に対して

## 規則與接續
- `名詞 + に対して`
- `普通形（名詞・な形容詞 + の） + に対して`

## 用法說明
表示動作施加的情感或行為對象（對於…），或前後兩者的對比（與…相反）。與單純提示話題的 [[JP_N3_30_nitsuite|〜について @related_to]] 不同，「〜に対して」帶有明確的對立或指向性指向性也不同於評價性的 [[JP_N3_28_nitotte|〜にとって @related_to]]。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#FF477E"><ruby>誰<rt>だれ</rt></ruby>に<ruby>対<rt>たい</rt></ruby>しても</span><span style="color:#3498DB"><ruby>親切<rt>しんせつ</rt></ruby>で、みんなから<ruby>好<rt>す</rt></ruby>かれています。</span>
  中文：他對任何人都很親切，非常受大家歡迎。
- 日文：<span style="color:#2ECC71"><ruby>兄<rt>あに</rt></ruby>が</span><span style="color:#FF477E"><ruby>活発<rt>かっぱつ</rt></ruby>なのに<ruby>対<rt>たい</rt></ruby>して、</span><span style="color:#2ECC71"><ruby>弟<rt>おとうと</rt></ruby>は</span><span style="color:#3498DB">とてもおとなしい<ruby>性格<rt>せいかく</rt></ruby>です。</span>
  中文：哥哥很活潑相對地，弟弟的個性則非常文靜。
