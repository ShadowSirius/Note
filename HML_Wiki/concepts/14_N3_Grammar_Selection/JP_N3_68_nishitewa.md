# 〜にしては

## 規則與接續
- `名詞 + にしては`
- `動詞・い形容詞普通形 + にしては`
- 常接在表示「身分、年齡、程度、條件」等名詞或普通形後面，表示「以…來說…、按…標準看有點不合預期」。

## 用法說明
「〜にしては」用來表示：以某個標準、身份、年齡、條件來看，後面的結果和一般預期不太一樣，帶有「沒想到、算是意外」的語感。  
和 [[JP_N3_33_wari_ni|〜わりに（は）@related_to]] 很接近，但「〜にしては」更常強調「以這個條件來說乎意料」」「〜わりに(は)」則較偏向單純比較程度。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#FF477E"><ruby>見た目<rt>みため</rt></ruby>にしては</span><span style="color:#3498DB"><ruby>若<rt>わか</rt></ruby>いです。</span>
  中文：他以外表來說是年輕。

- 日文：<span style="color:#FF477E">この<ruby>値段<rt>ねだん</rt></ruby>にしては、</span><span style="color:#3498DB"><ruby>味<rt>あじ</rt></ruby>がいいです。</span>
  中文：以這個價格來說味道算是不錯。

- 日文：<span style="color:#2ECC71"><ruby>子供<rt>こども</rt></ruby>にしては</span><span style="color:#FF477E"><ruby>字<rt>じ</rt></ruby>が</span><span style="color:#E67E22">とても</span><span style="color:#3498DB">きれいです。</span>
  中文：以小孩子來說字寫得非常漂亮。
