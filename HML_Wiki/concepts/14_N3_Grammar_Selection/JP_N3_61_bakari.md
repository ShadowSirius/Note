# 〜ばかり

## 規則與接續
- 名詞 + ばかり
- 動詞て形 + ばかり（してばかりいる）
- 〜ばかりで / 〜ばかりだ

## 用法說明
表示某種人事物或行為「占得太多、太偏」，帶有抱怨、嫌多、失衡的語氣，可譯為「淨是、光是...」。

和 [[JP_N3_60_dake|〜だけ @related_to]] 相比，「ばかり」更強調比例偏重與不滿不滿和「しか〜ない」相比，「ばかり」不一定要接否定，但常有「怎麼又是這個」的感覺。另「動詞た形 + ばかり」也可表示「剛...」（參見 [[JP_N3_19_ta_bakari_da|〜たばかりだ @related_to]]），要和這裡的「偏重」用法分開。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

  中文：這個房間淨是書，完全沒有玩具。

- 日文：<span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#FF477E"><ruby>言い訳<rt>いいわけ</rt></ruby>ばかりして、</span><span style="color:#3498DB"><ruby>全然<rt>ぜんぜん</rt></ruby><ruby>勉強<rt>べんきょう</rt></ruby>しない。</span>
  中文：他淨是在找藉口，完全不讀書。

- 日文：<span style="color:#2ECC71"><ruby>最近<rt>さいきん</rt></ruby>は</span><span style="color:#FF477E"><ruby>仕事<rt>しごと</rt></ruby>ばかりで、</span><span style="color:#3498DB"><ruby>週末<rt>しゅうまつ</rt></ruby>も<ruby>休<rt>やす</rt></ruby>めない。</span>
  中文：最近淨是工作，連週末也沒辦休息。
