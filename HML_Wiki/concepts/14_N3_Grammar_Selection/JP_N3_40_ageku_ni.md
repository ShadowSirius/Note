# 〜あげく（に）

## 規則與接續
- `動詞た形 + あげく（に）`
- `名詞 + の + あげく（に）`

## 用法說明
表示經過一番波折、長時間的努力或糾結之後，最終得出的結果（多半是負面、不理想的），強調過程的曲折與結果的落差，語氣偏書面，帶有無奈或後悔的意味。

與「〜末（すえ）に」的辨析：
- 「〜あげく（に）」：強調經過一番波折後產結果，**結果多為負面、不理想**，帶無奈或後悔語感。
- 「〜末に」：同樣表示「經過一段過程後的最終結果」，但**語感中性**，結果可好可壞（例：話し合いの末に、合意に達した），更常見於書面與正式場合。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E">さんざん<ruby>悩<rt>なや</rt></ruby>んだあげく、</span><span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#3498DB"><ruby>仕事<rt>しごと</rt></ruby>を<ruby>辞<rt>や</rt></ruby>めることにした。</span>
  中文：苦惱了很久之後，他最終決定辭職。
- 日文：<span style="color:#FF477E"><ruby>長<rt>なが</rt></ruby>い<ruby>議論<rt>ぎろん</rt></ruby>のあげく、</span><span style="color:#3498DB"><ruby>結論<rt>けつろん</rt></ruby>は<ruby>出<rt>で</rt></ruby>なかった。</span>
  中文：經過長時間的討論，最終還是沒有得出結論。
