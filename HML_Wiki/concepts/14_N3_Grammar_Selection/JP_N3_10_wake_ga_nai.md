# 〜わけがない

## 規則與接續
- `動詞/い形容詞 普通形 + わけがない`
- `な形容詞 + な / 名詞 + の + わけがない`

## 用法說明
根據常理或強烈的主觀判斷，全面否定某事的可能性，意為「不可能、絕不會」，語氣十分堅決。與部分否定的 [[JP_N3_11_wake_dewa_nai|〜わけではない @related_to]] 意思完全不同，切勿混淆。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E">ピーマンが<ruby>嫌<rt>きら</rt></ruby>いな</span><span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>が、</span><span style="color:#3498DB">そんな<ruby>野菜炒<rt>やさいいた</rt></ruby>めを<ruby>食<rt>た</rt></ruby>べるわけがない。</span>
  中文：討厭青椒的他，不可能會吃那種炒青菜的。
- 日文：<span style="color:#FF477E"><ruby>全然<rt>ぜんぜん</rt></ruby><ruby>練習<rt>れんしゅう</rt></ruby>していないのに、</span><span style="color:#3498DB"><ruby>試合<rt>しあい</rt></ruby>に<ruby>勝<rt>か</rt></ruby>てるわけがないでしょう。</span>
  中文：明明完全沒練習，比賽怎麼可能會贏嘛。
