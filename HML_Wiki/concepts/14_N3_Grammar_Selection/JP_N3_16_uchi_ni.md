# 〜うちに

## 規則與接續
- `動詞辞書形/ている形/ない形 + うちに`
- `い形容詞 + うちに`／`な形容詞 + な + うちに`／`名詞 + の + うちに`

## 用法說明
表示「趁著某狀態尚未改變前做某事」，若錯過這段時間該行為將變得困難，常帶有說者的主觀急迫感。與 [[JP_N3_17_aida_ni|〜間に @related_to]] 相比，「〜うちに」更強調時機的急迫性與可能錯失的遺憾，「〜間に」則單純描述期間內的動作。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71">スープが</span><span style="color:#3498DB"><ruby>冷<rt>さ</rt></ruby>めないうちに、</span><span style="color:#FF477E"><ruby>早<rt>はや</rt></ruby>く</span><span style="color:#3498DB"><ruby>飲<rt>の</rt></ruby>んでください。</span>
  中文：趁著湯還沒冷，請快點喝吧
- 日文：<span style="color:#FF477E"><ruby>日本<rt>にっぽん</rt></ruby>に<ruby>留学<rt>りゅうがく</rt></ruby>しているうちに、</span><span style="color:#3498DB"><ruby>色<rt>いろ</rt></ruby>な<ruby>所<rt>ところ</rt></ruby>へ<ruby>旅行<rt>りょこう</rt></ruby>したいです。</span>
  中文：趁著在日本留學的時候，想去很多地方旅行。
