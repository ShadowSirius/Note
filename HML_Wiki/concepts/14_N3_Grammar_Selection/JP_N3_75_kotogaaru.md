# 〜ことがある（経験）

## 規則與接續
- `動詞た形 + ことがある`
- `動詞た形 + ことがない`（否定：從來沒有...過）

## 用法說明
表示「曾經做過某事／有過某經驗」，常和「一度、以前、子どものころに」等時間詞一起出現。  
要注意不要和「動詞辞書形 + ことがある」混淆混淆後者是「有時候、偶爾會...」，而這裡一定是「た形」，重點在經驗。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71"><ruby>私<rt>わたし</rt></ruby>は</span><span style="color:#E67E22"><ruby>一度<rt>いちど</rt></ruby></span><span style="color:#3498DB"><ruby>北海道<rt>ほっかいどう</rt></ruby>へ<ruby>行<rt>い</rt></ruby>ったことがあります。</span>
  中文：我曾經去過北海道一次。

- 日文：<span style="color:#E67E22"><ruby>子供<rt>こども</rt></ruby>のころに</span><span style="color:#2ECC71"><ruby>私<rt>わたし</rt></ruby>は</span><span style="color:#3498DB"><ruby>海<rt>うみ</rt></ruby>で<ruby>泳<rt>およ</rt></ruby>いだことがあります。</span>
  中文：我小時候曾經在海裡游泳過。

- 日文：<span style="color:#2ECC71"><ruby>私<rt>わたし</rt></ruby>は</span><span style="color:#E67E22"><ruby>以前<rt>いぜん</rt></ruby></span><span style="color:#3498DB">この<ruby>店<rt>みせ</rt></ruby>のラーメンを<ruby>食<rt>た</rt></ruby>べたことがあります。</span>
  中文：我以前曾經吃過這家店的拉麵。
