# 〜反面

## 規則與接續
- `動詞普通形 + 反面`
- `い形容詞普通形 + 反面`
- `な形容詞 + な反面`
- `名詞 + である反面`（口語中也常見 `名詞 + の反面` 的說，但正式教材以 `である反面` 較能清楚表現）

## 用法說明
表示同一事物有「相反的一面」，前半句先提出一種特徵後半句再補出與之對照的另面，語感常接近「雖然……，但另方面……」。  
和 `〜一方（で）` 相近，但 `〜反面` 更常用來強調同一主體的正反對比，帶有「優點／缺點、好處／麻煩」這類明顯反差的語感。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71">この<ruby>薬<rt>くすり</rt></ruby>は</span><span style="color:#FF477E"><ruby>眠<rt>ねむ</rt></ruby>くなる<ruby>反面<rt>はんめん</rt></ruby></span><span style="color:#3498DB">、<ruby>効き目<rt>ききめ</rt></ruby>が<ruby>強<rt>つよ</rt></ruby>い。</span>
  中文：這款藥雖然會讓人想睡，但另方面藥效很強。

- 日文：<span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#FF477E"><ruby>優<rt>やさ</rt></ruby>しい<ruby>反面<rt>はんめん</rt></ruby></span><span style="color:#3498DB">、<ruby>決<rt>き</rt></ruby>めたことはなかなか<ruby>変<rt>か</rt></ruby>えない。</span>
  中文：他雖然很溫，但相對地，一旦決定了就不太會改變。

- 日文：<span style="color:#2ECC71"><ruby>勉強<rt>べんきょう</rt></ruby>は</span><span style="color:#FF477E"><ruby>楽<rt>たの</rt></ruby>しい<ruby>反面<rt>はんめん</rt></ruby></span><span style="color:#3498DB">、<ruby>時間<rt>じかん</rt></ruby>が<ruby>足<rt>た</rt></ruby>りなくなることもある。</span>
  中文：學習雖然有趣，但另方面也可能會時間不夠
