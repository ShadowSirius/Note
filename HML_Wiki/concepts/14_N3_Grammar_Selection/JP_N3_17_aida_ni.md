# 〜間に

## 規則與接續
- `動詞辞書形/ている形 + 間に`
- `い形容詞 + 間に`／`な形容詞 + な + 間に`／`名詞 + の + 間に`

## 用法說明
表示在某個持續狀態的期間內生了另短暫、瞬間的動作。與不加「に」的「〜間」不同：「〜間」指整段期間動作皆持續發生，「〜間に」則是期間內時間點才發生。與 [[JP_N3_16_uchi_ni|〜うちに @related_to]] 相比，「〜間に」較客觀、不強調急迫感。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E"><ruby>子供<rt>こども</rt></ruby>が<ruby>寝<rt>ね</rt></ruby>ている<ruby>間<rt>ま</rt></ruby>に、</span><span style="color:#3498DB"><ruby>家事<rt>かじ</rt></ruby>を<ruby>終<rt>お</rt></ruby>わらせました。</span>
  中文：趁著小孩睡著的期間，我把家事做完了。
- 日文：<span style="color:#FF477E"><ruby>留守<rt>るす</rt></ruby>の<ruby>間<rt>ま</rt></ruby>に、</span><span style="color:#2ECC71"><ruby>荷物<rt>にもつ</rt></ruby>が</span><span style="color:#3498DB"><ruby>届<rt>とど</rt></ruby>いたようです。</span>
  中文：不在家的期間，好像有包裹送來了。
