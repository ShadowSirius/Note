# 〜てくれる

## 規則與接續
- `動詞て形 + くれる`

## 用法說明
表示他人主動為說者（或說者一方）做某事，主詞為「施恩者」。與 [[JP_N3_22_temorau|〜てもらう @related_to]] 相比，「〜てくれる」更強調對方是主動幫帶有強烈的感謝之意，語法結構為「（對方）が（我）に〜てくれる」。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E"><ruby>荷物<rt>にもつ</rt></ruby>が<ruby>重<rt>おも</rt></ruby>かったので、</span><span style="color:#2ECC71"><ruby>親切<rt>しんせつ</rt></ruby>な<ruby>人<rt>にん</rt></ruby>が</span><span style="color:#3498DB"><ruby>運<rt>はこ</rt></ruby>んでくれた。</span>
  中文：因為行李很重，有位好心人幫搬了。
- 日文：<span style="color:#FF477E"><ruby>誕生日<rt>たんじょうび</rt></ruby>の<ruby>日<rt>にち</rt></ruby>に、</span><span style="color:#2ECC71"><ruby>彼氏<rt>かれし</rt></ruby>が</span><span style="color:#3498DB"><ruby>綺麗<rt>きれい</rt></ruby>なネックレスを<ruby>買<rt>か</rt></ruby>ってくれた。</span>
  中文：生日那天，男朋友買了一條漂亮的項鍊我。
