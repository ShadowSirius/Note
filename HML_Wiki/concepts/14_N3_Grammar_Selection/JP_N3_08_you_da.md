# 〜ようだ

## 規則與接續
- `動詞/い形容詞 普通形 + ようだ`
- `な形容詞 + な / 名詞 + の + ようだ`

## 用法說明
表主觀推測或比喻口語與書面語皆可用。比 [[JP_N3_07_rashii|〜らしい @related_to]] 更憑直覺與主觀感受，且較口語的 [[JP_N3_06_mitai_da|〜みたいだ @related_to]] 更正式、書面。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#3498DB"><ruby>誰<rt>だれ</rt></ruby>もいないね。どうやら<ruby>道<rt>みち</rt></ruby>を<ruby>間違<rt>まちが</rt></ruby>えたようだ。</span>
  中文：都沒有人在呢我們好像走錯路了。
- 日文：<span style="color:#2ECC71"><ruby>彼女<rt>かのじょ</rt></ruby>の<ruby>笑顔<rt>えがお</rt></ruby>は、</span><span style="color:#3498DB">まるで<ruby>太陽<rt>たいよう</rt></ruby>のように<ruby>明<rt>あか</rt></ruby>るい。</span>
  中文：她笑容宛如太陽般明朗。
