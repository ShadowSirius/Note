# 〜のに（逆接）

## 規則與接續
- `用言普通形 + のに`
- `な形容詞語幹 + な + のに`
- `名詞 + な + のに`

## 用法說明
表示與預期相反的結果，帶有不滿、遺憾或驚訝等強烈主觀情緒，是本組逆接句型中口語使用頻率最高、情緒最直接的一種。

與 [[JP_N3_31_mono_no|〜ものの]]、[[JP_N3_38_nagara_mo|〜ながらも]]、[[JP_N3_32_kuseni|〜くせに]] 的辨析：
- 「〜のに」：主觀情緒最直接，可用於任何人稱，語氣可從單純遺憾到強烈不滿都適用，口語常用。
- 「〜ものの」：陳述前後矛盾的事實，語氣客觀、書面，情緒色彩淡。
- 「〜ながらも」：強調兩件事「同時並存」的矛盾，書面語感，情緒比「のに」溫
- 「〜くせに」：比「のに」情緒更強烈、更帶輕蔑責備，且幾乎只用於評價他人（第二、三人稱）。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#FF477E"><ruby>一生懸命<rt>いっしょうけんめい</rt></ruby><ruby>勉強<rt>べんきょう</rt></ruby>したのに、</span><span style="color:#3498DB"><ruby>試験<rt>しけん</rt></ruby>に<ruby>落<rt>お</rt></ruby>ちた。</span>
  中文：明明拚讀書了，卻沒考過。
- 日文：<span style="color:#FF477E">もう<ruby>春<rt>はる</rt></ruby>なのに、</span><span style="color:#3498DB">まだ<ruby>寒<rt>さむ</rt></ruby>い。</span>
  中文：明明已經是春天了，卻還是很冷。
