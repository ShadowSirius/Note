# 〜けれど（も）

## 規則與接續
- `動詞普通形 + けれど（も）`
- `い形容詞普通形 + けれど（も）`
- `な形容詞語幹 + だ + けれど（も）`
- `名詞 + だ + けれど（も）`

## 用法說明
表示前後兩句內相反或有對照，中文可譯為「雖然……但是……」「……不過……」。`けれど（も）` 比 `しかし` 更口語，也比帶有明顯不滿、遺憾語氣的 [[JP_N3_39_noni|〜のに @related_to]] 來得溫。和 `〜が` 類似，但 `けれど（も）` 在日常會話中更常見，句尾單獨使用時也可用來婉轉收尾、留有餘地。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71">この<ruby>靴<rt>くつ</rt></ruby>は</span><span style="color:#FF477E"><ruby>高<rt>たか</rt></ruby>いけれど、</span><span style="color:#3498DB"><ruby>長<rt>なが</rt></ruby>く<ruby>使<rt>つか</rt></ruby>えます。</span>
  中文：這雙鞋雖然貴，但是很耐用。

- 日文：<span style="color:#2ECC71"><ruby>私<rt>わたし</rt></ruby>は</span><span style="color:#FF477E"><ruby>忙<rt>いそが</rt></ruby>しいけれど、</span><span style="color:#3498DB">できるだけ<ruby>毎朝<rt>まいあさ</rt></ruby><ruby>運動<rt>うんどう</rt></ruby>します。</span>
  中文：我雖然很忙，但還是會盡量每早上運動。

- 日文：<span style="color:#2ECC71"><ruby>今日<rt>こんにち</rt></ruby>は</span><span style="color:#FF477E"><ruby>行<rt>い</rt></ruby>きたいけれど、</span><span style="color:#3498DB"><ruby>仕事<rt>しごと</rt></ruby>があって<ruby>無理<rt>むり</rt></ruby>です。</span>
  中文：今天雖然想去，但是有工作，沒辦。
