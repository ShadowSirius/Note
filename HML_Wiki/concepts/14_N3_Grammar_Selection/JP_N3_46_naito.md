# 〜ないと（いけない）

## 規則與接續
- `動詞ない形 + と（いけない）`
- `動詞ない形 + と`

## 用法說明
表示「不……不行、必須……」的口語義務表現，前面接動詞ない形。完整說 `〜ないといけない`，日常會話中常把後半省略成 `〜ないと`，語氣比 `〜なければならない` 更口語、更自然。  
另，`〜なくちゃ`／`〜なきゃ` 是更隨便的縮略說，常見於非常口語的對話。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71"><ruby>私<rt>わたし</rt></ruby>は</span><span style="color:#E67E22"><ruby>明日<rt>あした</rt></ruby>までに</span><span style="color:#3498DB"><ruby>宿題<rt>しゅくだい</rt></ruby>を<ruby>終<rt>お</rt></ruby>わらないといけません。</span>
  中文：我必須在明天之前把作業做完。

- 日文：<span style="color:#2ECC71"><ruby>会議<rt>かいぎ</rt></ruby>の<ruby>資料<rt>しりょう</rt></ruby>は</span><span style="color:#E67E22"><ruby>今日中<rt>きょうじゅう</rt></ruby>に</span><span style="color:#3498DB"><ruby>提出<rt>ていしゅつ</rt></ruby>しないといけません。</span>
  中文：會議資料必須在今天之內交。

- 日文：<span style="color:#FF477E"><ruby>明日<rt>あした</rt></ruby><ruby>仕事<rt>しごと</rt></ruby>があるから、</span><span style="color:#2ECC71"><ruby>今日<rt>こんにち</rt></ruby>は</span><span style="color:#E67E22"><ruby>早<rt>はや</rt></ruby>く</span><span style="color:#3498DB"><ruby>寝<rt>ね</rt></ruby>ないといけない。</span>
  中文：因為明天有工作，所以今天必須早點睡。
