# 〜わけだ

## 規則與接續
- `用言普通形 + わけだ`
- `な形容詞語幹 + な + わけだ`
- `名詞 + という/である + わけだ`

## 用法說明
表示根據已知事實推導出理所當然的結論，語感為「難怪、也就是說。與偏向理性推測的 [[JP_Grammar_50_C45_hazu_desu_beki_desu|〜はずだ @related_to]] 不同，「〜わけだ」側重於得知原因後的恍然大悟與理解，而非單純的推理判斷。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#FF477E"><ruby>日本<rt>にっぽん</rt></ruby>に10<ruby>年<rt>ねん</rt></ruby>も<ruby>住<rt>す</rt></ruby>んでいたから、</span><span style="color:#3498DB"><ruby>日本語<rt>にほんご</rt></ruby>がペラペラなわけだ。</span>
  中文：他在日本住了10年之久，難怪日文說這麼流利。
- 日文：<span style="color:#FF477E"><ruby>消費税<rt>しょうひぜい</rt></ruby>が10%になったから、</span><span style="color:#3498DB"><ruby>買い物<rt>かいもの</rt></ruby>が<ruby>高<rt>たか</rt></ruby>く<ruby>感<rt>かん</rt></ruby>じるわけですね。</span>
  中文：因為消費稅成10%了，也就是說東西會覺得變貴了呢
