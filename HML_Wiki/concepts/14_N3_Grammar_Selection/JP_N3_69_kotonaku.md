# 〜ことなく

## 規則與接續
- `動詞原形（辞書形） + ことなく`
- 常見於書面語，表示「不...地、沒有...就...」
- 也常見固定搭配：`一度も〜ことなく`、`休むことなく`、`会うことなく`

## 用法說明
「〜ことなく」表示在沒有做前項動作的情況下，就進行後項動作，語氣較正式、帶有書面感。  
和「〜ずに／〜ないで」意思相近，但「〜ことなく」更常出現在文章、演說述文文日常會話通常較少用。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#FF477E"><ruby>休<rt>やす</rt></ruby>むことなく</span><span style="color:#3498DB"><ruby>働<rt>はたら</rt></ruby>いた。</span>
  中文：他不休息地工作了。

- 日文：<span style="color:#2ECC71"><ruby>私<rt>わたし</rt></ruby>たちは</span><span style="color:#FF477E"><ruby>先生<rt>せんせい</rt></ruby>に<ruby>会<rt>あ</rt></ruby>うことなく</span><span style="color:#3498DB"><ruby>卒業<rt>そつぎょう</rt></ruby>した。</span>
  中文：我們沒有見到老師就畢業了。

- 日文：<span style="color:#2ECC71"><ruby>彼<rt>かれ</rt></ruby>は</span><span style="color:#FF477E"><ruby>泣<rt>な</rt></ruby>くことなく</span><span style="color:#3498DB"><ruby>真実<rt>しんじつ</rt></ruby>を<ruby>話<rt>はな</rt></ruby>した。</span>
  中文：他沒有哭就說了真相。
