# お〜になる

## 規則與接續
- `お + 動詞ます形去掉「ます」 + になる`
- 常見敬語也可用 `ご + サ變動詞語幹 + になる`，如：`ご利用になる`、`ご覧になる`

## 用法說明
表示對對方或第三者的動作抬高，屬於尊敬語，意思是「您……／他做……」。  
與 `〜られる` 相比，`お〜になる` 也能表示尊敬，但語感通常較明確、較正式式而 [[JP_N3_70_sonkeigo_verbs|おっしゃる・いらっしゃる・召し上がる @related_to]] 等則是不規則的尊敬表現，需另記憶。與降低自身動作的謙讓語 [[JP_N3_52_osuru|お〜する @related_to]] 方向相反。

## 實用例句
> [!tip] 句子結構色彩：：主語/主題 |  | 核心/謂語 |  | 修飾語 |  | 時間/場所/副詞

- 日文：<span style="color:#2ECC71"><ruby>部長<rt>ぶちょう</rt></ruby>は</span><span style="color:#E67E22">いま</span><span style="color:#3498DB"><ruby>会議室<rt>かいぎしつ</rt></ruby>へお<ruby>入<rt>い</rt></ruby>りになります。</span>
  中文：部長現在要進會議室。

- 日文：<span style="color:#2ECC71"><ruby>先生<rt>せんせい</rt></ruby>は</span><span style="color:#FF477E"><ruby>来週<rt>らいしゅう</rt></ruby>の<ruby>発表<rt>はっぴょう</rt></ruby>に</span><span style="color:#3498DB">ご<ruby>参加<rt>さんか</rt></ruby>になります。</span>
  中文：老師下週會參加發表會。

- 日文：<span style="color:#2ECC71"><ruby>社長<rt>しゃちょう</rt></ruby>は</span><span style="color:#E67E22"><ruby>毎朝<rt>まいあさ</rt></ruby></span><span style="color:#3498DB">お<ruby>早<rt>はや</rt></ruby>く<ruby>起<rt>お</rt></ruby>きになります。</span>
  中文：社長每早上都很早起床。
